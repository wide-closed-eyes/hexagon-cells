
# Тестовое задание Backend (v5)
## Исходные данные
Создать массив вида [ [h3_index, level, cell_id], ... ] из H3 гексагонов 12-го уровня заполняющих круг с центом 56 с.ш. 38 в.д. и радиусом 7км, \
Где:
* level: integer в диапазоне -47... -120 равный ( (h3_index / 512) % 74) - 120.
* cell_id: integer в диапазоне 1...100 равный ( (h3_index / 512) % 100) + 1.
* (% - это остаток от деления, / - это целочисленное деление)

Точное условие принадлежности кругу: h3.greatCircleDistance(ЦентрКруга, ЦентрГексагона) < 7км.\
h3.greatCircleDistance - это функция из библиотеки H3.


## API
С использованием фреймворка FastAPI разработать API с четырьмя конечными точками типа GET.\
Первые три из них возвращают данные в формате JSON.

1. hex\
    Возвращает элементы массива исходного датасета входящих в заданный гексагон\
    Параметр hex - индекс гексагона\
    Пример запроса\
    http://localhost:8000/hex?hex=8a11aa648367fff\
    Фрагмент правильного ответа (очерёдность h3 не важна)
    ~~~
    [["8c11aa6483601ff",-120,93], ["8c11aa6483603ff",-119,94], …]
    ~~~

2. avg\
    Возвращает массив гексагонов заданного разрешения, с медианным значением level сгруппированным по cell_id из исходного датасета\
    Параметр resolution – разрешение от 0 до 12.\
    Медиану округлять до целого в меньшую сторону.\
    Пример запроса\
    http://localhost:8000/avg?resolution=0\
    Фрагмент правильного ответа (очерёдность h3 не важна)
    ~~~
    [["8011fffffffffff",-84,1], ["8011fffffffffff",-83,2], …]
    ~~~

3. bbox\
    Возвращает элементы массива исходного датасета ограниченных заданным полигоном border.\
    Гексагоны возвращаемой выборки не должны пересекаться границей полигона, т.е. должны целиком умещаться внутри полигона.\
    Параметр border - массив координат lat/lon разделенных запятыми.\
    Пример запроса \
    http://localhost:8000/bbox?border=56.035953/37.911440,56.280315/37.589786,56.0/37.182514

4. bbox_kml\
    Как и bbox, но в ответе не JSON, а файл kml с гексагонами. \
    При открытии ссылки в браузере файл должен скачиваться.
